# JavaScript & TypeScript Pre-Course Materials

A short coding refresher before the Playwright course. Playwright tests are written in
TypeScript, so a few language basics make the rest of the training much easier.

Use this before training:
- `PRE-COURSE-REFRESHER.md`
- `questions/README.md`

Suggested flow:
1. Read the refresher once end-to-end (about 45 minutes).
2. Go through all 20 formatted questions in `questions/`.
3. Read theory + question + explanation for each.
4. Try the examples yourself: save one as `example.ts` and run `node example.ts`
   (Node.js 24 runs TypeScript files directly).
5. Bring open questions to the course.

When you are comfortable here, continue with the [Playwright refresher](../playwright/README.md).
